 # Escape 3D – Splash & Home Screen

Pure HTML + CSS + JS (koi library nahi).

## Files
- `index.html` – splash screen + home screen ka structure
- `style.css` – saara UI design (sky, ring, road, ball, buttons)
- `script.js` – loading bar, splash → home transition, sound toggle, coins

## Run karna
`index.html` ko browser me open karo (ya VS Code ka Live Server use karo).

## GitHub pe push
```bash
git init
git add .
git commit -m "Add splash and home screen"
git branch -M main
git remote add origin https://github.com/<username>/escape3d.git
git push -u origin main
```

## Free hosting (GitHub Pages)
Repo → Settings → Pages → Branch: `main` / root → Save.
